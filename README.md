
# Restaurant Management Database System

## Project Overview

This project involves the design and development
of a relational database system for a restaurant.

The system manages customer information, waiters,
restaurant tables, food and drink orders, menu
items, categories and ingredients.

## Objectives

- Design a conceptual Entity Relationship Diagram.
- Convert the ER diagram into a relational schema.
- Implement the database using MySQL.
- Insert sample records into the database.
- Retrieve restaurant order information using SQL.
- Generate reports using multiple table joins.
- Identify customers affected by expired ingredients.

## Technologies Used

- MySQL
- SQL
- Git
- GitHub

## Database Entities

1. Customer
2. Waiter
3. Restaurant Table
4. Customer Order
5. Order Item
6. Menu Item
7. Item Category
8. Ingredient
9. Menu Item Ingredient

## Main Features

- Customer management
- Waiter and order management
- Menu and category management
- Ingredient tracking
- Order reporting
- Expired ingredient identification

## How to Run

1. Install MySQL.
2. Open MySQL Workbench.
3. Run the SQL files in the database folder
   in numerical order.
4. Execute the queries in 04_queries.sql.
